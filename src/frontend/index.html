Welcome to Privemail

Your local, private AI email assistant.

This wizard will help you set up your encryption, connect to Google, and select your AI model.

Create Password

Set a Master Password. This will be used to encrypt your database locally.

Connect Gmail

Privemail needs a credentials.json file from Google Cloud to access your Gmail.

Before clicking Authorize:
  1. Go to console.cloud.google.com and create an OAuth Client ID (Desktop App type).
  2. Download the JSON file and rename it to credentials.json.
  3. Place it in your Privemail data folder:
    • Windows installer: %APPDATA%\Privemail\
    • Mac installer: ~/Library/Application Support/Privemail/
    • Running from source: src/app_data/

⚠️ A browser window will open after you click Authorize. Sign in and approve permissions.

Select AI Model

Choose the local AI model to power your assistant.
